# Security Policy

## Scope

CrawlForge is a web-crawling utility intended for authorized testing and discovery. Please do not use it to access systems without permission.

## Reporting a vulnerability

Please do not publish exploit details or sensitive target data in a public issue. Contact the repository maintainer privately through the security contact configured on the GitHub repository. Include a concise description, impact, reproduction steps using a safe local example where possible, and the affected version.

Do not include live credentials, session cookies, private URLs, or personal data in a report.

## Safe handling

Crawl output may include sensitive paths, query parameters, form metadata, and strings that resemble secrets. Store output securely and review it before sharing.
